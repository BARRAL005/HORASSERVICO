Usar no celular

Depois de publicar o app no GitHub Pages, você pode adicionar um atalho à tela inicial:

iPhone (Safari)
Abra o site no Safari → toque em Compartilhar → Adicionar à Tela de Início.
Android (Chrome)
Abra o site no Chrome → menu ⋮ → Adicionar à tela inicial ou Instalar app.

O app funciona sem conta e sem enviar os registros para um servidor. Como o armazenamento é local, faça backup antes de trocar de aparelho ou limpar os dados do navegador.
